# Mini Macro 0.0.2

macOS 14 이상에서 동작하는 SwiftUI 마우스 매크로 앱입니다. 설치된 앱 이름은 **Mouse Macro**입니다. 마우스만 녹화하며, 키보드는 중지 감지에만 사용합니다. 공개 배포 파일은 Apple Silicon·Intel을 함께 지원하는 Universal 앱입니다.

## 설치

[Releases](https://github.com/ynifamily3/mini-macro/releases)에서 공증된 DMG 또는 ZIP을 내려받으세요. DMG를 열어 **Mouse Macro.app**을 **Applications**로 끌어 놓거나, ZIP의 앱을 응용 프로그램 폴더로 옮깁니다.

Homebrew로도 설치할 수 있습니다.

```sh
brew install --cask ynifamily3/tap/mini-macro
```

Homebrew가 `untrusted tap` 오류를 표시하면 해당 cask의 신뢰를 등록한 뒤 설치를 다시 실행하세요.

```sh
brew trust --cask ynifamily3/tap/mini-macro
```

macOS 14 이상, Apple Silicon 또는 Intel Mac이 필요합니다. 앱과 DMG는 Developer ID로 서명하고 Apple 공증 티켓을 첨부했습니다. `SHA256SUMS.txt`로 다운로드 파일의 체크섬을 확인할 수 있습니다.

## 소스에서 실행

```sh
./Scripts/build-app.sh --open
```

생성된 앱은 `build/Mouse Macro.app`입니다. Swift 6 이상과 Xcode 또는 Command Line Tools가 필요하며 외부 패키지는 사용하지 않습니다. 일반 빌드는 현재 Mac의 아키텍처를 대상으로 합니다. 키체인의 코드 서명 인증서를 사용하며, 인증서 SHA-1을 로컬 `.codesign-identity` 파일에 고정합니다. 이 파일은 Git에서 제외하며 `build/`를 지워도 유지됩니다. 지정한 인증서를 찾지 못하면 빌드를 중단하고 임시 서명으로 대체하지 않습니다. `CODE_SIGN_IDENTITY`로 인증서 이름 또는 SHA-1을 명시해 변경할 수도 있습니다. 이 명령은 개발용이며, 공증 배포는 아래 별도 스크립트를 사용합니다.

손쉬운 사용 권한을 유지하려면 같은 앱 경로, 번들 ID(`ing.miel.mousemacro`), 서명 인증서를 유지해 빌드하세요. macOS는 [지정 요구사항(Designated Requirement)](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)으로 앱의 코드 정체성을 확인합니다. 개발용 앱에서 Developer ID로 서명한 배포용 앱으로 전환하면 시스템 설정에서 권한을 다시 부여해야 할 수 있습니다.

## 처음 사용하기

1. 앱 상단의 **입력 모니터링 → 허용**을 눌러 시스템 설정에서 Mouse Macro를 켭니다.
2. **손쉬운 사용 → 허용**에서도 Mouse Macro를 켭니다. 이 권한은 재생에 필요합니다.
3. **시스템 알림 → 허용**은 선택입니다. 허용하지 않아도 중지 안내 오버레이와 소리는 동작합니다.
4. 권한을 켰는데 시작할 수 없다면 앱을 완전히 종료하고 다시 엽니다. 권한 목록에 없다면 `+`로 설치한 `Mouse Macro.app`을 추가합니다.

권한은 macOS 시스템 설정에서 사용자가 직접 허용해야 합니다.

## 녹화·재생

- **녹화 모드**에서 **전체 동작** 또는 **클릭 위치만**을 선택한 뒤 **녹화 시작**을 누르고 3초 안에 대상 화면으로 이동합니다. 선택한 모드는 앱을 다시 열어도 유지됩니다.
- **전체 동작**은 마우스 이동, 좌·우·보조 버튼, 연속 클릭, 드래그, 세로·가로 스크롤을 기록합니다. 앱 자체의 제어 버튼 클릭은 제외합니다.
- **클릭 위치만**은 버튼을 누른 좌표와 누름·해제 시간만 저장합니다. 이동 경로, 드래그 경로, 스크롤, 녹화 시작 시 커서 위치는 저장하지 않습니다. 버튼을 놓는 위치도 누른 좌표로 고정해 드래그로 재생되지 않게 합니다. 재생할 때는 클릭할 좌표로 바로 이동하며 클릭 사이의 시간 간격을 유지합니다.
- 어느 앱에서든 **Esc**를 누르면 녹화가 끝납니다. 앱의 **녹화 끝내기** 버튼도 사용할 수 있습니다.
- 반복 횟수 **1~9,999회**를 설정하고 **반복 재생**을 누릅니다. 3초 뒤 원래 화면 좌표와 속도로 재생하며, 반복 사이에는 0.35초 간격을 둡니다.
- **재생이 시작된 뒤 마우스를 움직이거나 클릭·스크롤·키보드 입력을 하면 즉시 중지**합니다. 앱 외부에서 생성된 다른 자동화 입력도 중지 사유로 취급합니다. 준비 시간 동안은 화면을 옮길 수 있고 Esc로 취소할 수 있습니다.
- 중지와 완료는 다른 앱 위에도 나타나는 안내창으로 표시하며, 알림 권한이 있으면 macOS 알림도 보냅니다.
- 앱 창에서 `⌘⇧R`은 녹화, `⌘⇧P`는 재생, `⌘.`은 중지입니다. 메뉴 막대에서도 녹화·재생·중지를 실행할 수 있습니다. 녹화와 재생 단축키는 전역 단축키가 아닙니다.

마지막 녹화는 `~/Library/Application Support/MouseMacro/last-recording.json`에 자동 저장됩니다. **파일로 저장 / 불러오기**로 모드가 포함된 `.mousemacro` 파일을 관리할 수 있습니다. 기존 파일은 전체 동작 녹화로 불러옵니다. 모든 데이터는 로컬에만 저장합니다.

## 매크로 보관함

앱 위쪽의 **매크로 보관함** 버튼이나 메뉴 막대의 **매크로 → 매크로 보관함**으로 엽니다. 녹화를 끝내거나 `.mousemacro` 파일을 가져오면 보관함에 자동으로 추가됩니다. 기존 마지막 녹화도 처음 실행할 때 가져오며 원본은 유지합니다.

여러 녹화를 이름별로 보관하고, 이름 변경·파일 내보내기·녹화 화면에서 열기를 할 수 있습니다. 삭제한 파일은 macOS 휴지통으로 이동합니다. 자동화에서 사용하는 매크로는 해당 단계를 먼저 제거해야 삭제할 수 있습니다.

## 녹화 동작 편집

녹화 화면의 **동작 편집**, 또는 보관함에서 매크로를 선택한 뒤 **동작 편집**을 누르세요. 보관함 위쪽의 **새 매크로**로 녹화 없이 직접 작성할 수도 있습니다.

```text
클릭       (320, 240) · 왼쪽
시간 지연  0.5초
이동       (640, 480)
시간 지연  1초
클릭       (640, 480) · 오른쪽
```

항목을 선택하면 오른쪽에서 좌표, 대기 시간, 클릭 버튼·누르는 시간을 수정합니다. 위쪽 버튼으로 클릭·이동·시간 지연을 추가하고, **더 추가**에서 버튼 누름·해제·드래그·스크롤을 추가할 수 있습니다. 아래쪽에서 복제·삭제·순서 변경을 합니다. 항목이 많으면 200개씩 나누어 표시합니다.

변경 후 **저장** 또는 `⌘S`를 누르세요. 저장 전에는 기존 녹화에 반영하지 않으며, 변경사항을 남긴 채 닫으면 확인합니다. 기존 매크로의 ID를 유지하므로 이 매크로를 사용하는 자동화도 수정된 동작을 실행합니다. 현재 녹화 화면에 열려 있던 같은 매크로도 함께 갱신합니다. 좌표·시간이 잘못되거나 버튼의 누름·해제 순서가 맞지 않으면 저장할 수 없습니다.

파일에는 `actions` 배열로 각 이벤트의 동작 종류, X·Y 좌표, 녹화 시작 후 경과 시간(`time`) 등을 저장합니다. 클릭은 내부적으로 누름·해제 두 이벤트이고 대기는 이벤트 사이의 시간 차입니다. 편집기는 같은 위치의 연속된 누름·해제를 클릭 하나로 묶어 보여주고, 대기를 별도 항목으로 풀어 보여줍니다. 드래그와 겹쳐 누른 버튼은 개별 이벤트로 유지하고, 처음·마지막 대기와 트랙패드 세부 정보도 보존합니다. 저장 형식은 기존 `.mousemacro` 파일과 호환됩니다.

## 자동화 편집기

**자동화 편집기**는 녹화 화면과 별도 창으로 열립니다. 왼쪽 `+`로 새 자동화를 만들고, 팔레트의 노드나 보관함 매크로를 캔버스에 끌어 놓습니다. 팔레트를 클릭해 추가할 수도 있습니다. 노드 본체를 드래그해 배치하고 오른쪽 출력 포트를 다음 노드의 왼쪽 입력 포트로 끌어 연결하세요. 출력 포트와 입력 포트를 차례로 클릭해도 연결됩니다.

노드를 클릭하면 오른쪽 설정 패널에서 이름·매크로·시간·이미지 조건을 바꿀 수 있습니다. 패널의 **출력 연결** 목록으로도 연결 대상을 선택할 수 있습니다. 상단 패널 버튼으로 설정을 접거나 펼칩니다. 연결선을 선택하고 Delete를 누르면 연결을 지우고, 노드를 선택한 상태에서 Delete를 누르면 노드와 관련 연결을 지웁니다. 시작 노드는 지울 수 없습니다. 노드의 우클릭 메뉴에서는 복제·삭제를 할 수 있습니다.

캔버스의 빈 곳을 드래그하거나 휠을 움직여 화면을 이동합니다. `⌘`/Option+휠 또는 트랙패드 핀치로 확대·축소하며, 왼쪽 아래의 버튼으로 확대·축소·화면에 맞추기를 할 수 있습니다. **자동 정렬**은 연결 순서에 따라 노드를 정렬합니다. 노드의 위치·연결·설정과 화면의 이동·확대 상태는 자동 저장됩니다.

- **매크로 실행**: 보관함에서 녹화를 선택하고 해당 매크로의 반복 횟수를 지정합니다.
- **대기**: 지정한 시간 동안 기다립니다.
- **이미지 IF**: 이미지가 나타날 때까지 기다립니다. **발견**(초록색)과 **시간 초과**(주황색) 출력에 각각 다음 노드를 연결합니다. 두 경로를 같은 후속 노드로 합치거나, 다른 IF로 연결해 조건을 더 검사할 수 있습니다.
- **종료**: 한 회를 마칩니다. 남은 전체 반복이 있으면 시작 노드로 돌아갑니다.
- **전체 종료**: 남은 반복까지 포함해 전체 실행을 마칩니다.

시작 노드에서 이어진 경로만 실행합니다. 실행 경로의 모든 출력 포트(IF의 두 출력 포함)를 연결해야 실행할 수 있습니다. 떨어져 있는 노드는 초안으로 보관할 수 있으며 실행하지 않습니다. 순환 연결은 허용하지 않으며, 반복은 상단의 전체 횟수나 매크로 노드의 반복 횟수로 설정합니다.

실행 버튼을 누르면 3초 뒤 시작합니다. 실행 중에는 편집을 잠그고, 현재 노드와 지나간 연결선을 강조합니다. 아래 **실행 기록**을 펼치면 매크로와 IF 결과를 확인할 수 있습니다. 직접 마우스·키보드를 조작하면 매크로 재생뿐 아니라 이미지 검색·대기 중에도 전체 자동화를 중지합니다.

예시:

```text
시작 → 매크로 A → 이미지 IF (완료 버튼, 최대 10초)
                    ├ 발견 → 매크로 B ─┐
                    └ 시간 초과 → C ─┤
                                     ↓
                                  1초 대기 → 종료
```

### 이미지 IF 설정

1. 편집기 위쪽에서 **화면 기록 권한 허용**을 눌러 Mouse Macro를 허용합니다. 권한은 사용자가 직접 켜야 하며 macOS가 요구하면 앱을 다시 실행합니다.
2. **이미지 파일**로 PNG/JPEG/TIFF를 가져오거나 **화면에서 선택**을 눌러 캡처한 화면에서 찾을 부분을 드래그합니다. 캡처에서 Mouse Macro의 모든 창과 안내 오버레이는 제외합니다.
3. 검색할 디스플레이, 유사도 기준, 최대 대기 시간(0~300초), 검색 간격(0.2~5초)을 정합니다. 최대 대기 0초는 한 번만 검사합니다.
4. 필요하면 검색 영역을 좁힙니다. 화면에서 선택하거나 전역 좌표 X·Y·너비·높이를 직접 지정할 수 있습니다.
5. **일치 여부 테스트**로 현재 화면에서 발견되는지 확인합니다. 선택적으로 **발견한 이미지의 중심 클릭**을 켤 수 있습니다.

이미지와 화면의 배율·크기·테마가 같아야 합니다. 현재 매칭은 회전·확대·축소를 자동으로 보정하지 않는 밝기 패턴 기반의 정규화 상관 비교이며, 유사도는 확률이 아닙니다. 단색 이미지는 잘못된 일치를 방지하기 위해 거부합니다. 화면에서 글자·무늬가 포함된 작은 영역을 선택하고 검색 영역을 좁히는 방법을 권장합니다. 템플릿은 10MB·800만 픽셀 이하, 한 변 3~4,096픽셀을 지원합니다.

캡처 실패, 화면 기록 권한 해제, 디스플레이 분리 등의 오류는 ‘이미지 없음’으로 처리하지 않고 전체 실행을 중지합니다. 이미지와 캡처는 이 Mac에서만 처리하며 외부로 전송하지 않습니다.

보관함은 `~/Library/Application Support/MouseMacro/Macros/`, 자동화는 `Automations/`에 각각 JSON 파일로 저장합니다. 자동화에 등록한 이미지는 해당 JSON에 함께 저장되므로 원본 이미지 파일을 옮겨도 유지됩니다. 자동화 한 개는 시작·기본 종료를 포함해 최대 1,002개 노드를 지원합니다.

이전 개발 버전의 순서형 자동화는 처음 열 때 노드와 연결선으로 자동 변환합니다. 원본 JSON은 같은 폴더의 `<UUID>.json.v2-backup` 파일로 한 번 보관합니다. 기존 반복·분기·분기 이후의 공통 경로와 전체 종료 동작을 유지합니다. 변환된 파일은 노드 편집기를 포함한 버전에서 사용하세요.

## 현재 범위

- 키 입력과 Shift·Command 등의 조합은 녹화하지 않습니다.
- 위치는 절대 화면 좌표입니다. 재생 시 대상 창과 디스플레이 배치를 녹화할 때와 맞춰야 합니다. 현재 화면 바깥의 좌표가 있는 녹화는 실행하지 않습니다.
- 최대 녹화 길이는 30분, 최대 이벤트 수는 200,000개입니다.
- 녹화를 드래그 중 끝내거나 재생을 중지할 때는 매크로가 누른 버튼을 해제합니다.
- 입력 감지 중단, 권한 해제, 화면 잠자기·세션 전환 시 실행을 중지합니다. 앱 종료 시에도 버튼과 이벤트 감지를 정리합니다.
- 입력 감지는 읽기 전용 [Core Graphics 이벤트 탭](https://developer.apple.com/documentation/coregraphics/cgevent/tapcreate(tap:place:options:eventsofinterest:callback:userinfo:))을 사용합니다. 재생 이벤트에는 식별자를 부여하고 하드웨어 입력 억제를 해제해 중지 입력을 받을 수 있게 합니다.

## 검증

```sh
swift test
./Scripts/build-app.sh
```

자동 테스트는 정확한 반복 횟수, 녹화된 대기 시간 유지, 취소 후 예약 종료, 드래그 버튼 균형, 파일 검증·왕복 저장, 합성 이벤트 식별, 키보드 미저장, 트랙패드 스크롤 정밀도·단계를 확인합니다. 클릭 위치만 모드의 이동·스크롤 제외, 클릭 좌표·간격 보존, 클릭 없는 녹화 처리, 눌린 버튼 해제, 기존 파일 호환성도 확인합니다.

자동화 테스트는 매크로 연결·반복, IF 참/거짓, 캡처 오류 시 분기 금지, 중첩 종료, 대기·이미지 검사 중 취소를 검증합니다. 합성 이미지에서 패턴의 위치·경계 탐지, Retina 배율과 전역/검색 영역 좌표 변환, 보관함의 저장·재실행·기존 녹화 이관도 검증합니다.

노드 자동화 테스트는 이전 형식의 양쪽 IF 경로·반복·공통 후속 경로 보존, 전체 종료, 재연결과 순환 차단, 삭제 시 연결 정리, 미완성 출력 검증, 연결되지 않은 초안 제외, 이미지 검사 취소 후 클릭·분기 금지, 확대 중심 보존, 위치·연결·화면 상태의 저장, 원본 백업을 검증합니다.

현재 버전은 자동 테스트 50개를 통과했습니다. 동작 편집의 시간·좌표 변환, 드래그·스크롤 보존, 잘못된 입력 차단과 기존 매크로 연결 유지도 검증합니다. 로컬 UI 점검에서는 팔레트·보관함 매크로의 드래그 추가, 노드 이동, 포트 드래그·차례 클릭 연결, 연결선 선택·Delete·재연결, 자동 정렬, 캔버스 이동·확대, 재실행 후 배치 보존을 확인했습니다. 별도 대기 자동화의 두 번 반복과 입력 감지 중단, 화면에서 템플릿 선택, 실제 화면의 이미지 발견·시간 초과 분기, 이미지 검색 중 전체 중지도 확인했습니다. 개별 매크로가 대상 앱을 올바르게 조작하는지는 사용 환경에 따라 확인해야 합니다. Intel 실행 환경에서의 실기 점검은 수행하지 않았습니다.

## 서명·공증 배포

키체인에 Developer ID Application 인증서와 `notarytool` 자격 증명을 준비한 뒤 실행합니다. 자격 증명과 개인 키는 저장소에 넣지 않습니다.

```sh
NOTARY_PROFILE="your-keychain-profile" ./Scripts/release.sh
```

스크립트는 Universal 앱을 별도 폴더에서 빌드하고, Hardened Runtime과 보안 타임스탬프로 서명합니다. 앱 공증·staple 후 ZIP과 Applications 링크를 포함한 DMG를 만들고, DMG도 서명·공증·staple합니다. Gatekeeper 검증을 통과한 파일과 SHA-256 체크섬을 `dist/v0.0.2/`에 생성합니다. 기존 개발용 `.codesign-identity`는 변경하지 않습니다. 공증 요구사항은 [Apple 문서](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)를 참고하세요.
